# Revit Model

検証には Autodesk 公式の日本仕様 意匠サンプルモデル Revit 2024 を使用しています。

`.rvt` ファイル本体は容量および配布条件を考慮し、GitHub公開対象外としています。

本リポジトリでは、Revitモデル本体ではなく、Revit集計表から書き出したTXT / CSVを入力データとして使用しています。

## Phase 3B用の集計表調整

Phase 3B：Roomカテゴリ追加の検証に向けて、Revitモデル内のRoom関連集計表を確認しました。

Roomカテゴリ用の入力データ候補として、以下の集計表を使用します。

```text
05 部屋 仕上表 作業用
```

この集計表は、Roomカテゴリの品質チェック・AI Readiness Assessment用に、部屋名、階、仕上情報などを確認できるため、初期MVPの入力候補として採用します。

また、Roomカテゴリ検証で `Area` を扱うため、作業用集計表に `面積` 列を追加しました。

この調整は、PoC用の入力データを書き出すための集計表表示調整であり、設計判断、施工判断、Revitモデルの自動修正を目的としたものではありません。
